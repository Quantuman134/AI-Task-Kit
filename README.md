# AI Task Kit

This is a repo to build tools (like Skills) for various of task based on language models. As we increasingly rely on AI automation to handle most of our workload, and these tools are the primary means through which human participate in and maintain control over automated workflows. So I will try to write them manually as much as possible...

## Design Philosophy

1. **A consistent, plug-and-play system.** Combine shared context with a task-specific package so that each tool can be deployed and used in a consistent, straightforward way.
