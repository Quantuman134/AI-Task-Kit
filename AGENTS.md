# Agent Guide

## Scope

- This guide applies to agents across tasks. When updating it, add only rules that apply generally.

## Communication

- Keep chat messages and documents concise, clear, and well organized. Use consistent terminology and short section titles.
- Write documents for readers who have not seen the chat. Introduce concepts before formulas, label settings clearly, and use tables where helpful. Keep each item to one or two sentences when possible.
